# Code of conduct

Be kind, be specific, assume good intent.

- Critique code and ideas, never people.
- No harassment, insults, or discriminatory language, in any channel connected to this project.
- Respect people's time: search before asking, and include what you tried.
- Don't share other people's private information, including anything from their conversations or simulated lives.

Maintainers may edit or remove contributions, and restrict participation, for behaviour that breaks these rules. To report a problem, contact the maintainers privately through GitHub.
