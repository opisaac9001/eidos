# Getting Help

Choose the place that best matches what you need:

| Need | Where to go |
| --- | --- |
| A reproducible bug | [Open a bug report](https://github.com/opisaac9001/eidos/issues/new?template=bug_report.yml) |
| An idea or feature proposal | [Open a feature request](https://github.com/opisaac9001/eidos/issues/new?template=feature_request.yml) |
| Something odd in his life (a strange thought, a contradiction, a repeat) | [Open a life report](https://github.com/opisaac9001/eidos/issues/new?template=life_report.yml) |
| A question or early idea | [GitHub Discussions](https://github.com/opisaac9001/eidos/discussions) |
| Setting up models | [docs/MODELS.md](docs/MODELS.md) and [docs/LOCAL_MODELS.md](docs/LOCAL_MODELS.md) |
| A security vulnerability | Follow [SECURITY.md](SECURITY.md) |

Before posting, remove model provider keys, operator tokens, private server addresses and anything personal from your conversations with him.
