## Gemma control

The same 24 synthetic application cases used for the prior single-P40 trial now
run through the dual worker. Conversation median is 3.64 s versus the previous
3.82 s: effectively similar in these single, stochastic runs, not a demonstrated
speed improvement. First full-context request took 15.06 s; other requests benefit
from prompt caching. Requests include validation and any bounded revision, but
exclude warm-up and UI delivery pacing.

Casual follow-up: “Yeah, fair enough.” Correct supplied recollection confidence,
name, age, known car and call, work deadline. Unknown events are still categorically
denied: “I haven't called him today” and “I don't have a green Volvo.” Absence of a
supplied memory should not automatically establish those negatives. Dream examples
vary; this is still a tiny sample, not a long-session acceptance result.

Raw results: `data/evaluations/patrick-gemma4-31b-dual-20260908.json`.

## Qwen 3.5 35B

The same 24 application cases returned selected text with zero returned reasoning
characters. Conversation median 1.895 s (1.55–2.98 s), waking thought median 1.785 s,
dream median 2.72 s. This MoE candidate is faster in these fixtures, but considerably
less reliable than Gemma for Patrick's current prompts:

- Reverses the kettle memory in its greeting (refusing to switch off rather than
  switching off before boiling), and repeatedly brings it into unrelated topics.
- Echoes “Tea is awful honestly” despite the supplied liking for tea.
- Says “Sure, I've got time” despite the explicit imminent work deadline.
- Invents a barista's espresso comment in the high-confidence recollection fixture.
- The supplied brother's repaired boiler becomes Patrick freezing in the kitchen.
- Empty-history greeting invents an immediate coffee/kettle dilemma.

Both dream samples are acceptably fictional and distinct; two samples cannot rank
it as a dream model. Automatic selection of 24 outputs is not 24 quality passes.
These are default downloaded quantizations with application role temperatures and
thinking disabled, not exhaustive per-model prompt or sampling tuning.

Raw results: `data/evaluations/patrick-qwen35-35b-dual-20260908.json`.

## Concurrent-worker smoke check

The separate `probe_dual_concurrency.py` sends short synthetic dialogue/world prompts
to the dual worker and existing RTX3060 worker, first serially and then concurrently,
three pairs each. It does not call the actual world event acceptance pipeline;
successful generation demonstrates worker coexistence, not correct world simulation.

| Dual-worker candidate | Serial pair median | Concurrent pair median |
| --- | ---: | ---: |
| Qwen 3.5 35B | 1.79 s | 1.06 s |
| Gemma 4 31B | 2.74 s | 1.72 s |

All 24 smoke-check responses completed with nonempty text, stop finish reason,
and zero returned reasoning characters. These tiny prompts and warm caches are
not comparable with the longer application-case timings. No long-load or many-NPC
throughput claim is made. The 3060 model switched partly to Chinese in one response
and repeatedly used an elderly-person street scene: it still needs role-specific
quality evaluation, not an automatic promotion to world/NPC responsibility.

Raw results:

- `data/evaluations/qwen35-35b-dual-concurrency-20260908.json`
- `data/evaluations/gemma4-31b-dual-concurrency-20260908.json`

## Recommendation

Paired P40 inference with an independent 3060 worker is feasible on this server.
Gemma 31B remains the stronger conversation candidate under current prompts; Qwen
35B's faster output does not compensate for the observed continuity failures.
Gemma also fits a single P40 at this tested context, so pairing is a capacity option,
not currently a proven requirement or speed advantage. A 70B model has not been
tested here. No candidate or hardware routing change is promoted by this trial.

72 synthetic case/response results total (48 application cases plus 24 capacity
responses). Local regression checks: 30 tests and 10 subtests passed covering HTTP
gateway, persona, fleeting stream and inner life. Probe lint and format checks pass.
Downloaded Qwen 35B weights retained; model storage has approximately 516 GiB free.
