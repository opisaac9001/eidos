# Lived-day integration — September 8, 2026

This is a first integrated pass across activity, interruptions, travel, relationship
context, presentation and real-model testing. It is not a claim that a whole human
life, all household activities, or every social interaction is now simulated.

## What changed

- **Work has stages.** New execution records distinguish preparation, focused work
  and finishing; learning and repair have their own small profiles. The explicit
  `household_dishes` recipe separates gathering, washing and putting away. A title
  containing “wash dishes” cannot authorize cleaning by itself.
- **A finished stage survives interruption.** Washing reduces actual accumulated
  dish load even if putting away is interrupted. It happens once, with a link to
  the source execution. Completing a repair stage does not guarantee a repaired
  object: final world validation still owns that result.
- **Actual effort requires presence and resources.** Sleep, another conversation,
  phone calls, incident responses, travel, absent companions and unavailable objects
  do not count as work. A needed borrowed object cannot remain magically usable.
- **Returning to work is recorded.** An interrupted task can be resumed or deferred
  from its active intention and current energy. Rechecking the same evidence does
  not repeatedly reconsider the choice. Regaining the thread costs up to 90 seconds
  of actual available time. This is a small deterministic decision policy, not yet
  a complete model-driven attention system.
- **Lost windows remain reconsiderable.** They become interrupted, not automatically
  failed projects or fulfilled promises. Explicit rescheduling of the same task
  preserves prior effort without counting the time between sessions twice. External
  commitments still require their existing negotiation path.
- **Travel has a real middle.** Accepted plans cause departure and later arrival at
  route-duration boundaries. There is no invented earlier departure to conceal
  lateness. During transit Patrick is at neither endpoint, cannot visit, cannot
  accrue work there, and cannot see either endpoint's occupants. Sleeping, active
  scenes and incident responses can delay departure. The authored fixture retains
  its historical traversal behavior; natural mode uses the new executor.
- **Shared boundaries are ordered.** At the same instant, arrival precedes work,
  completion precedes departure. The real-model trial caught and helped diagnose an
  earlier version that left before validating finished work.
- **Calls occupy time.** Natural-mode accepted incoming calls receive a bounded
  three-to-twelve-minute interval, complete between hourly cognition updates, and
  prevent a second simultaneous incoming call. Existing authored call fixtures stay
  compatible. Callback and other interaction lifecycles still need further duration
  work; this does not claim all communication is now continuous.
- **NPC dialogue gets owned relationship impressions.** A resident can draw on a
  recent promise made to them, follow-through, a let-down or an apology. Exact detail
  fades after three days; this adapter stops supplying the impression after thirty.
  The HTTP boundary checks speaker and audience ownership. Patrick's autobiographical
  memory is not replaced with this operational ledger. An apology does not erase
  the original event or compel forgiveness.
- **Current-state speech has targeted checks.** Bounded reply repair catches selected
  obvious completion/arrival contradictions; an unresolved blocking draft is withheld.
  Old, confidently mistaken memories remain possible. These checks are conservative
  heuristics, not a general truth detector.
- **Transport and domain identifiers agree better.** The agency slug pattern is now
  anchored; prose with a valid substring no longer passes as an activity identifier.
  Prompt instructions clarify identifiers, fractional priority and destination fields.
  Domain validation remains authoritative; invalid output is not silently coerced.

## UI

- “His day right now” shows recorded effort, stages, interruptions and unfinished
  sessions. The Now page shows the same information and active journey progress.
- Conversation messages are updated by identity rather than rebuilding the whole
  log during paced replies. Existing nodes and the reader's scroll position survive.
- Unread indicators distinguish looking at the latest messages from reading older
  messages or leaving the tab hidden. Read markers persist locally when available.
- The day context remains available on small screens. Inspection does not add
  buttons that dictate Patrick's actions; ordinary interaction remains messaging/visits.
- Disposable preview worlds have an explicit synthetic-data banner.

### Real models, isolated histories

The baseline Qwen 14B trials showed false completion, false arrival, invented
interruptions and reversed lending history. Better current-state wording, the
boundary-order correction and guarded repair improved the targeted distinctions,
but Qwen still added unsupported conversational details. It is not declared fixed.

Gemma 31B gave consistent short distinctions in three repeats of four personal
cases: still working, finished, still travelling and interrupted. Examples:

- “Not yet. Still working on them.”
- “Yeah, all done.”
- “Almost. Just about there.”

Initial Gemma 12B resident replies were uniformly cautious. A balanced ownership
instruction produced different responses in two later passes: cautious after a
missed promise/apology, willing after follow-through. These are small samples;
variation, independent goals and less formulaic NPC speech need more evaluation.

The final twelve-hour application run used **Gemma 31B on one P40, Gemma 12B on
the other P40, and Qwen 7B on the RTX3060**. This was not a dual-P40 pooled-model
trial. Thinking was requested off. The three-worker concurrency check took 3.94
seconds; median request time across the run was 2.23 seconds. These measure
inference, not the user-facing human speech/delivery pacing.

The run added 435 events and reopened with an identical snapshot. The complete
synthetic history contained two journeys, three completed activities, eight stage
completions, eleven recorded thoughts, sleep and one dream. It also contained two
safely rejected planning proposals: their motivations used past-completion wording
that the existing conservative validator rejects. No crash or automatic replacement
plan followed. This over-rejection remains a known tuning issue, not a clean-model
claim. The synthetic fixture supplied the first two activities; the third accepted
activity arose during model execution.

## Remaining depth

More recipes (particularly cooking and laundry), ingredient/tool effects per stage,
uncertain task estimates, flexible preparation, deliberate mid-route changes and
encounters, richer attention decisions, and relationship effects beyond ordinary
dialogue remain. The existing world is not a complete physical city/economy.
Phone durations are now elapsed-time records, but callbacks/visitors need further
work. Matching supported past accomplishments in planning motivations without
allowing new fabricated success needs a source-aware validation design.

No production deployment, live-world resume, model promotion, or historical migration
was performed. Final restoration verified Qwen 14B on both P40 workers (11434/11435)
and Qwen 7B on the RTX3060 worker (11436), all with 8192-token contexts. The temporary
test tunnel was closed; the separate preview remains available.
